# 小部 第6章（小誦経）観察→行動ペア たたき台

**用途:** 毎日の行動指針（理解・観察 → 行動）  
**主ソース:** [南伝大蔵経 第24巻 小部経典一](https://true-buddhism.com/sutra/palisanzo/)（アラナ精舎）  
**照合ソース:** K.R. Norman訳 The Minor Readings (PTS)  
**経:** Khp 1 三帰依 / Khp 2 十学処 / Khp 3 三十二分身 / Khp 4 沙弥問答 / Khp 5 吉祥経 / Khp 6 宝経 / Khp 7 壁外施食経 / Khp 8 蔵経 / Khp 9 慈経

> 小誦経（Khuddakapāṭha）全9章から35ペア。  
> 三帰依から慈経まで、修行生活のあらゆる側面をカバーする構成。  
> Khp 9 慈経は k05 とは別角度（語・拡大・対治・夜）で採取。P35 は Khp 5 v.9「不動の心」実経 quote。

|---|---|---|---|---|---|

| KH6-P09 | 愚者に交わらず、賢者に交わり、尊ぶべき者を尊ぶ——人間関係が修行を形成する | 今日、「この関係は自分を高めるか下げるか」を一つ判断する | v.2·賢者への親近 | 「愚者に交わらず、賢者に交わり、尊ぶべき人を尊ぶ——此れが最上の吉祥なり」 | OK |
| KH6-P10 | 多くを学び、技術を具し、善く学ばれた律——知識と実践の組み合わせが吉祥 | 今日、一つの学びを修行と結びつける | v.3·学と律 | 「多くを学び、技術を具し、善く学ばれた律と、善く語られた言葉——此れが最上の吉祥なり」 | OK |
| KH6-P11 | 父母を養い、妻子を護り——在家者の日常の関係が修行の基盤 | 今日、家族の一人に具体的なケアを実践する | v.4·在家の善業 | 「父母を養い、妻子を護り、混乱なき職業——此れが最上の吉祥なり」 | OK |
| KH6-P12 | 施与し、正行し、親族を助け——布施と正行の吉祥、行為が修行 | 今日、何かを与える（物・言葉・時間）行為を一つ実践する | v.5·施と正行 | 「施与し、正行し、親族を助け、咎なき行い——此れが最上の吉祥なり」 | OK |
| KH6-P13 | 悪を離れ・酒を離れ・法において怠らず——離れることが吉祥の積み重ね | 今日、一つの悪い習慣に気づき、それを「離れる」と意図する | v.6·離悪 | 「悪を離れ、酒を離れ、法において怠らず——此れが最上の吉祥なり」 | OK |
| KH6-P14 | 聖者に遇い・聖なる法を聴き・法を論ずる——法を聴くことが吉祥 | 今日、経典や法話を一節読む | v.7·聴法 | 「聖者に遇い、聖なる法を聴き、法を論ずる——此れが最上の吉祥なり」 | OK |
| KH6-P15 | 苦行と梵行・聖諦の見・涅槃の実現——出世間の吉祥が究極 | 今日の修行を「聖諦の見」に向ける | v.8·梵行·涅槃 | 「苦行と梵行と、聖諦の見と、涅槃の実現——此れが最上の吉祥なり」 | OK |
| KH6-P16 | 世の法によって心が動かされず・憂なく・清らかに——最高の吉祥は不動の心 | 動揺が来たとき、「此れは世の法、動かされない」と一つ立つ | v.9·不動の心 | 「世の法によって心が動かされず、憂なく、塵なく、安穏なる者——此れが最上の吉祥なり」 | OK |
