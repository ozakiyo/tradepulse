| SY4-P22 | 道は修しなければ果を生じない——聞くだけでは解脱しない | 今日、一つの善法を実際に「修する」——意図するだけでなく行う | 修することの果 | 「修しない者に果はなし。修する者に果あり」 | OK |

| SY4-P24 | 在家の正道——欺かず、傷つけず、正しく命を全うする | 今日の仕事·家事で「正命に合っているか」と一度振り返る | 在家の正命 | 「在家者も、邪命を捨てて、正命によって命を全うすべし」 | OK |

| SY4-P26 | 月は徐々に満ちる——八正道の修習も日々の積み重ね | 今日の修行に「月が徐々に満ちる」と観じ、焦らず続ける | 月の喩え | 「諸比丘、月が徐々に満ちるように、修行者も八正道を徐々に完成する」 | OK |
| SY4-P27 | 正語の四支——中傷語は分裂を生み、苦を増やす | 今日、「中傷語——人の悪口を言わなかったか」振り返る | 中傷語を離れる | 「中傷語を離れる——此処で聞きて彼処に語らず、彼処で聞きて此処に語らず、分裂せる者を和合させる」 | OK |
| SY4-P28 | 八支のうち今日修した支、欠けた支を如実に知る | 就寝前、八正道の八支を一つずつ数え、今日の実践を振り返る | 今日の八正道 | 「此の八支よりなる聖道を、如実に修すべし」 | OK |

**修正メモ:**
