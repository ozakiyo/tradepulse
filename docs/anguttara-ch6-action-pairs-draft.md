| AN6-P19 | 六識——眼·耳·鼻·舌·身·意識はすべて縁起によって生滅する | 今日の意識の一つに「縁起によって生じ、縁起によって滅す」と観る | 六識·縁起 | 「眼識は眼と色を縁として生ず。縁の滅とともに眼識は滅す」 | OK |
| AN6-P32 | 六処はすべて無我——眼·耳·鼻·舌·身·意は我でも我のものでもない | 感覚器官の一つに「これは我でも我のものでもない」と観る | 六処·無我 | 「眼は無我なり。無我なるものは我のものにあらず。此れを如実に知りて、眼に対して離欲する」 | OK |
