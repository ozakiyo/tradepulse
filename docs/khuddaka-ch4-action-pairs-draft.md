| KH4-P11 | 師子——諸の音に驚かず、風——網に捕らわれない | 今日の騒音·雑念に「師子のごとく動じない」と一度意図する | 犀角·師子 | 「諸の音に驚かない師子のごとく、網に捕らわれない風のごとく——独り犀の角のごとく歩め」 | OK |

| KH4-P13 | 色への執着を棄て、有への渇愛の根を観る | 今日の執着に「有への渇愛」の根があるか問う | 犀角·無量心 | 「無量の心で修し、一切の生命の友となり、有への渇愛を断って——独り犀の角のごとく歩め」 | OK |
| KH4-P14 | 犀の角の偈——一切の縛りを超えた独行者 | 就寝前、今日の修行を「独り、犀の角のごとく」完結する | 犀角·結 | 「師子のごとく、風のごとく、蓮のごとく——縛りなく汚れなく、独り犀の角のごとく歩め」 | OK |

**修正点（v1 たたき台）:**
- P01–P13: 犀角経は原典の偈の順序（生命→友→執着→自由→根→善友→独行→遊戯→四無量心→集中→師子→愛欲→無量心）に沿って配置
- P14: 犀角経の締め偈（師子·風·蓮）を「夜」カテゴリに配置
- P27: 慈経の中心偈「母が独り子を守る」を対人カテゴリに配置
- P34/P35: 牟尼経の独行を夜カテゴリとして二重配置し、総括に結び付け
