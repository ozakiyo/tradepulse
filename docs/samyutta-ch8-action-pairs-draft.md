|---|---|---|---|---|---|
| SY8-P21 | 四預流支を具えた者は不退転——仏·法·僧への浄信と戒が証 | 朝、「私は不退転の道を歩んでいる」と信心を一言確認する | 不退転の証 | 「聖なる弟子が仏·法·僧への浄信と戒を具えたとき——彼は不退転であり、悪趣への堕落はない」 | OK |
| SY8-P22 | 不退転を語ること——自分の修行の成果を誠実に人に伝える | 今日、修行の成果を一つ「善い変化」として人に誠実に伝える | 不退転の語り | 「善家の息子は——仏·法·僧への浄信と戒によって、自分の不退転を確認できる」 | OK |
| SY8-P23 | 善知識と互いに不退転を確認し合う——修行の進展を正直に話す | 今日、信頼できる人に自分の修行の状態を正直に話す | 不退転の確認 | 「善家の息子が仏への浄信·法への浄信·僧への浄信·戒を具えているならば——地獄·餓鬼·畜生への堕落を免れる」 | OK |
| SY8-P24 | 七つの支——仏·法·僧への浄信、戒、多聞、施、慧が預流の七支 | 今日の七支のうち一つ（施·多聞·慧など）を意識して実践する | 七支 | 「七支を具えた聖なる弟子は——苦の完全な滅尽に向けて不退転の歩みをする。七支とは仏·法·僧への浄信·戒·多聞·施·慧是なり」 | OK |
| SY8-P25 | 渇愛への随従が退転の原因——渇愛を離欲することが不退転の鍵 | 今日の退転につながる行為（過食·過言など）を「渇愛の現れ」と観て、一歩止める | 渇愛·不退 | 「渇愛に随従する者は退転する。渇愛を離欲する者は不退転の道を歩む——此れが修行の核心なり」 | OK |
| SY8-P26 | 預流果の光明——最大七生で苦を完全に滅する見通し | 今日の修行の苦しさを「七生以内に終わる苦の道」と観て、励む | 苦の終わり·七生 | 「此の聖なる弟子は——最大七生の間に天·人の世界を流転した後、苦の完全な滅を得る」 | OK |
| SY8-P27 | 五根の修習が不退転を支える——信·精進·念·定·慧を日々育てる | 今日、五根のうち最も弱い根に意識を向け、一つ具体的に実践する | 五根·不退転 | 「五根を具えた者は——悪趣に堕ちず、不退転の道を歩む。日々五根を育てることが梵行の基盤なり」 | OK |
| SY8-P28 | 今日の四預流支の状態——仏·法·僧への浄信と戒を日々育てる | 就寝前、四預流支のうち今日最もよく修できたものを一つ確認する | 四預流支·夜 | 「仏·法·僧への浄信と戒を——日々確認し、日々育てよ。此れが不退転の日々の修行なり」 | OK |
| SY8-P29 | 正語が不退転を支える——真実·柔和·有益な語りを日々育てる | 今日の発言を「真実·柔和·有益」で振り返り、一つ改善点を見つける | 正語·不退 | 「正語は聖なる弟子の基礎である——真実を語り、虚偽を離れた者は不退転の道を歩む」 | OK |
| SY8-P30 | 善知識との交流が不退転を支える——梵行の全てが善き仲間にかかっている | 今日、善知識（修行仲間）に連絡し、修行の状態を共有する | 仲間·梵行の全て | 「阿難よ、善き友·善き仲間·善き同修行者——此れは梵行の半分でなく全てである」 | OK |
| SY8-P31 | 慧根が五根の頂点——慧根によって他の根が集まり、定まり、修される | 朝、「今週は慧根を育てる」と意図し、四聖諦への観察を意識する | 慧根·五根の頂点 | 「五根の中で慧根が最勝である——此の慧根に依りて他の根は集まり、定まり、修される」 | OK |
| SY8-P32 | 信根を育てる——仏·法·僧への浄信が疑いと渇愛の対治 | 疑心や不安が来たとき「仏·法·僧を信じる」と一言心に決める | 信根·対治 | 「信根を具えた者は——渇愛と疑いに打ち勝ち、不退転の道を歩む。信根が修行の第一の土台なり」 | OK |
| SY8-P33 | 五根と四諦——五根の修習が苦·集·滅·道の知見を開く | 今日の苦しみを「五根のどれを育てるための縁か」と観て、修行の動機とする | 五根·四諦 | 「信·精進·念·定·慧の五根を修習する者は——四聖諦を如実に知見し、苦の完全な滅に至る」 | OK |
