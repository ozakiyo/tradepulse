## MN 13 大苦蘊経（P01–P12）

| id | 観察 | 行動 | 節 | quote（南伝照合） | 照合 |
|---|---|---|---|---|---|
| MM5-P01 | 諸欲·諸色·諸受の楽味·患·出離を如実知 | 快楽一つについて「楽味·患·出離」を問う | 導 | 「諸欲の楽味、諸欲の患、諸欲の出離とは何ぞや。諸色の……諸受の……」 | OK |
| MM5-P02 | 五種の欲妙——諸欲の楽味 | 感覚への執着を「五種の欲妙」と名づける | 諸欲 | 「五種の欲妙によって生じる快楽及び心の喜びが、諸欲の楽味是なり」 | OK |
| MM5-P03 | 癩病者·火坑——諸欲も亦復た是の如し | 快楽に近づきすぎたら火坑の譬喩を思い出す | 譬喩 | 「火坑に入り、身を焼き、更に大なる苦を受く。諸欲も亦復た是の如し」 | OK |
| MM5-P04 | 諸欲の患——束縛·狂乱·貪着 | 「欲しい」の裏に束縛と災患が見えているか問う | 諸欲 | 「五種の欲妙に縛られ、狂い、貪着し、災患を見ず、出离を知らずして受ける是なり」 | OK |
| MM5-P05 | 諸欲の出離——渇愛の除却 | 執着を「渇愛の除却」と名づける | 諸欲 | 「渇愛を除却し、渇愛の滅を如実知る是なり」 | OK |
| MM5-P06 | 六触処が苦蘊の集 | 苦を触→受→愛→取の流れとして見る | 縁起 | 「六触処が、此の苦蘊の集是なり……此の大苦蘊のみ有り」 | OK |
| MM5-P07 | 欲愛·有愛·非有愛——三愛 | 「欲しい」「離れたい」の裏の愛を一つ見る | 三愛 | 「欲愛·有愛·非有愛是なり」 | OK |
| MM5-P08 | 諸色の楽味·患·出離 | 見た対象について患·出離も見る | 諸色 | 「諸色の楽味、諸色の患、諸色の出離を如実知るべし」 | OK |
| MM5-P09 | 諸受の楽味·患·出離 | 三受を名づけ、楽味·患·出離を見る | 諸受 | 「諸受の楽味、諸受の患、諸受の出離を如実知るべし」 | OK |
| MM5-P10 | 裸形行者への論駁——遍知の誤り | 意見に患·出離の視点が欠けていないか見る | 問答 | 「諸欲の楽味·患·出離……汝は知るや」 | OK |
| MM5-P11 | 楽味·患·出離を如実知れば苦蘊を滅す | 苦蘊の一環（触·受·愛·取）を意識する | 遍知 | 「渇愛を除却し、取を執らず、此の大苦蘊を滅す」 | 要約※ |
| MM5-P12 | 大苦蘊の知は夜の反芻にも効く | 就寝前、執着を「苦蘊の一環」と見て手放す | 結 | 「六触処が、此の苦蘊の集是なり」 | OK |

※P11：南伝第13経の結語部を要約。楽味·患·出離の如実知と渇愛除却の連関は経意と一致。

## MN 22 漏尽経（P13–P24）

南伝正式名：**蛇喩経**（Alagaddūpama-sutta）。アラナ·章表記は漏尽経。

| id | 観察 | 行動 | 節 | quote | 照合 |
|---|---|---|---|---|---|
| MM5-P13 | 法を誤って掴む——水蛇の譬喩 | 教えを極端に解釈していないか問う | 導 | 「法を誤って掴む者あり、水蛇を誤って掴むが如し——自ら害を招く」 | OK |
| MM5-P14 | 水蛇を誤って掴めば咬まれ苦を受く | 法を論争の材料として掴んでいないか問う | 蛇喩 | 「巻き或は尾を掴む……誤って掴んだ故に、死或は死に等しき苦を受く」 | OK |
| MM5-P15 | 正しく掴めば害なし——慧で考察 | 学んだ一節の意味を慧で考察する | 蛇喩 | 「法を正しく掴めば、害を受けず……長きにわたる利益·安楽に至る」 | 要約※ |
| MM5-P16 | 諸欲は蛇の頭の譬喩——少味·多苦·多患 | 快楽の裏に「蛇の頭の過患」を思い出す | 欲喩 | 「諸欲は、蛇の頭の譬喩の如く、少味·多苦·多患、其中の過患尤も甚し」 | OK |
| MM5-P17 | 筏喩——渡るための、保有するために非ず | 教えを語るとき相手が執着しないよう注意 | 筏喩 | 「筏の譬喩の法を説く。渡るための、保有するために非ず」 | OK |
| MM5-P18 | 諸法をも捨て去れ、何况非法をや | 「私の正しい理解」の取る手を緩める | 筏喩 | 「筏の譬喩を理解すべし。諸法をも捨て去れ、何况非法をや」 | OK |
| MM5-P19 | 色·受·想·行·識に於て我·我所を見ず | 執着しやすい対象で「我·我所」を観察 | 無我 | 「色に於て我·我所を見ず……識に於て我·我所を見ず」 | OK |
| MM5-P20 | 五取蘊を捨断せ | 体調·感情を「蘊の集まり」と見る | 無我 | 「色を捨断せよ、受を捨断せよ……識を捨断せよ」 | OK |
| MM5-P21 | 以前も今も——苦のみ宣べ、苦の滅のみ宣べ | 確信の根拠が「正しい理解」か問う | 教示 | 「我、以前も今も、苦のみ宣べ、苦の滅のみ宣べ」 | OK |
| MM5-P22 | アリッタの誤見——誤った把握は自他を損す | 教えを自分の都合に曲げていないか問う | 誤見 | 「誤った把握によって我らを誹謗し、自らを損し、多くの不徳を為す」 | OK |
| MM5-P23 | 無我は自己否定ではなく——取る所なし | 自分を責めず、執着だけを手放す | 無我 | 「取る所なき所まで、我·我所の想を捨て去る」 | OK |
| MM5-P24 | 五蘊無我の観察は夜にも効く | 就寝前、執着を「取る所なし」と手放す | 無我 | 「色に於て我·我所を見ず……識に於て我·我所を見ず」 | OK |

※P15：正把握の利益は経中の蛇喩·法把握の結論部を要約。

| MM5-P32 | 見緣起者即見法——五取蘊は縁起已生 | 執着を「縁起の一環」と名づける | 縁起 | 「見緣起者、即ち法を見る……此五取蘊は、縁起已生なり」 | OK |
| MM5-P33 | 五取蘊は包攝·集合·結合された聚合物 | 対象を「包攝·集合·結合された蘊」と見る | 五取蘊 | 「此れ等の五取蘊は、包攝され、集合され、結合されている」 | OK |
