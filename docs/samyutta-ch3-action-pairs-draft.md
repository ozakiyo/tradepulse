## SN 35.13·43·60 触·受·愛·取の縁起（P07–P12）

| id | 観察 | 行動 | 節 | quote | 照合 |
|---|---|---|---|---|---|
| SY3-P07 | 一切とは六根·六境——この外に世界はない | 今日の経験を「六根のいずれか」に分類し、外を探すのを止める | 一切 | 「一切とは何ぞや。眼と色なり、耳と声なり……意と法なり」 | OK |
| SY3-P08 | 眼に縁りて触が生じ、触に縁りて受が生ずる | 感情が動いたとき「触→受→愛」の連鎖を一瞬観る | 触縁起 | 「眼と色を縁として眼識が生ずる。三者の会合が触なり。触に縁りて受が生ずる」 | OK |
| SY3-P09 | 楽受に縁りて愛が生じ、取が生じ、苦が生ずる | 快い受が来たら、愛に移る前に一息置く | 受·愛 | 「眼に縁りて色を見て、楽受を生ずる者は、色に縛られて住す」 | OK |
| SY3-P10 | 眼で色を見て相を取らず——六根を律する | 今日、一つの感覚入口に「相を取らない」と意図する | 根律儀 | 「比丘、眼で色を見て、相を取らず、細相を取らず、覚受の集を制し、根を護る」 | OK |
| SY3-P11 | 世界は触によって経験される——他者との接触も縁起 | 他者との接触で感情が動いたとき、「触→受→愛」の順を観る | 触と他者 | 「比丘、世界は触によって知られる。触に縁りて苦楽が生ずる」 | OK |
| SY3-P12 | 六根·六境——滅に向かって修する縁として観ずる | 朝、六根のうち一つを選び「この根の働きを観察する」と意図する | 滅へ | 「比丘、汝は此の六根に依りて、滅に向かいて修すべし」 | OK |

## SN 35.17–18·145–146 内空·外空（P13–P18）

| id | 観察 | 行動 | 節 | quote | 照合 |
|---|---|---|---|---|---|
| SY3-P13 | 内空——眼は空なり、恒有的な我·我所に非ず | 朝「見ている眼に我はない」と静かに観る | 内空 | 「比丘、眼は空なり。何故に空なるか。自己に非ず、自己に属するものに非ずが故なり」 | OK |
| SY3-P14 | 外空——色は空なり、恒有的な我·我所に非ず | 見た対象一つに「これも空なり、我·我所に非ず」と観る | 外空 | 「比丘、色は空なり。何故に空なるか。自己に非ず、自己に属するものに非ずが故なり」 | OK |
| SY3-P15 | 眼は燃えている——貪·瞋·癡の火によって | 何かに強く反応したとき「貪·瞋·癡の火が燃えている」と観る | 火説法 | 「諸比丘、一切は燃えている。貪の火によって、瞋の火によって、癡の火によって燃えている」 | OK |
| SY3-P16 | 厭離——聖弟子は眼に厭離を生じ、離貪し、解脱する | 強い感覚反応が来たら「これに厭離を生ずる」と観る | 離貪 | 「多聞の聖弟子は、眼に厭離を生じ……離貪する者は解脱する」 | OK |
| SY3-P17 | 七処に善巧——六根の集·滅·苦·出離を如実に知る | 感覚の対象が来たとき「集はどこか·滅はどこか」と一瞬当てはめる | 七処三観 | 「比丘、眼の集を如実に知り、眼の滅を如実に知り、眼の苦を如実に知り、眼の出離を如実に知る」 | OK |
| SY3-P18 | 内空·外空——今日もすべての経験は無我の縁起だった | 就寝前、感覚経験のうち一つに「空なり、縁起なり」と観て眠る | 内外空·夜 | 「眼は空なり、色は空なり——自己に非ず、自己に属するものに非ずが故なり」 | OK |

## SN 35.79·93–95 根律儀·感覚の修行（P19–P24）

| id | 観察 | 行動 | 節 | quote | 照合 |
|---|---|---|---|---|---|
| SY3-P19 | 舌根を守れば語の行いも清まる | 言葉を発する前に「舌根を守っているか」と確認する | 根律儀と語 | 「舌で味を識して、舌根を守る者は、語の行いを清め、梵行に住す」 | OK |
| SY3-P20 | 世界の生滅——眼が生じ消えるところに世界の生滅がある | 他者を見るとき「見るという縁起を観じている」と一瞬観る | 世界の生滅 | 「世界の生ずる処は、此の眼の生ずる処なり。世界の滅する処は、此の眼の滅する処なり」 | OK |
| SY3-P21 | 眼に対して貪があれば束縛——離貪が解脱の条件 | 一つの感覚への執着に気づいたら「貪を離れる」と意図する | 貪と解脱 | 「眼に対して貪あれば束縛あり。眼に対して貪なければ束縛なし」 | OK |
| SY3-P22 | 六根に縁って六愛が生ずる——根を守ることで渇愛を断つ | 欲しいという気持ちが来たら「これは六根から生じた愛」と観る | 六愛 | 「眼に縁りて眼愛が生ずる。耳に縁りて耳愛が生ずる……意に縁りて法愛が生ずる」 | OK |
| SY3-P23 | 世界の起——六触身の起こりにほかならない | 「世界」という概念が来たら、六根の縁起として観る | 世界の起 | 「諸比丘、世界の起は、此の六触身の起なり」 | OK |
| SY3-P24 | 貪愛が六根に結びついている者は縛られている | 朝、今日特に反応しやすい根を一つ観察すると決める | 縛 | 「眼に縁りて貪愛ある者は、眼に縛られている」 | OK |

## SN 35.13·60·82·85 世界の生滅·心の清め（P25–P28）

| id | 観察 | 行動 | 節 | quote | 照合 |
|---|---|---|---|---|---|
| SY3-P25 | 一切を如実に知ることが解脱の縁——見るたびに修行の機会 | 感覚が生じるたびに「これが修行の機会」と観じる | 一切の修習 | 「比丘、一切を如実に知ることで……一切に厭離し、離貪し、解脱に至る」 | OK |
| SY3-P26 | 眼と色を縁として眼識が生ずる——識は縁起、固定した相手像はない | 他者と話すとき、固定した「相手像」を手放して「縁起として見る」と観じる | 識の縁起 | 「眼と色を縁として眼識が生ずる。眼識は無常にして、変化し、滅するものなり」 | OK |
| SY3-P27 | 一切は苦——六処の生滅が苦の根 | 苦が来たとき「六処のいずれかを縁として生じた苦」と観る | 一切は苦 | 「諸比丘、一切は苦なり。何が一切か。眼は苦なり、色は苦なり……意は苦なり、法は苦なり」 | OK |
| SY3-P28 | 内外空——六根·六境、いずれも自己に非ず | 「私が見ている」ではなく「眼に縁りて見が生じている」と言い換える | 内外空と無我 | 「眼は空なり、色は空なり。何故か——自己に非ず、自己に属するものに非ずが故なり」 | OK |

## 総括（P29–P35）

| id | 観察 | 行動 | 節 | quote | 照合 |
|---|---|---|---|---|---|
| SY3-P29 | 今日も六根に依りて経験し、縁起の流れを生きた | 就寝前、今日最も反応した感覚入口を一つ振り返り、「無常」と観て眠る | 六根·夜 | 「眼は無常なり、耳は無常なり……意は無常なり。生滅するが故なり」 | OK |
| SY3-P30 | 独住——六根の対象に愛縛されない者が真の独住 | 今日の会話で「独住（対象に縛られない）」を一瞬意識する | 独住 | 「比丘、愛縛の伴なく住する者が、真の独住なり」 | OK |
| SY3-P31 | 触によって世界を知る——他者も同じ縁起のなかに住す | 他者の苦を見たとき「縁起の流れ」として慈悲心を向ける | 触と慈悲 | 「此の世界は触によって知られる。触に縁りて苦楽が生ずる」 | OK |
| SY3-P32 | 六処における苦·集·滅·道——四諦は六処を通じて理解される | 苦が来たとき、六処のどの根を縁として生じたかと観る | 六処と四諦 | 「眼に於ける苦を如実に知り、集を如実に知り、滅を如実に知り、道を如実に知る」 | OK |
| SY3-P33 | 根を守る者は、正念·正知に依りて住む | 感覚が生じるたびに「守っているか」と一息チェックする | 根律儀と正念 | 「根を護り、正念に依りて住み、正知に依りて住む比丘は、此の苦を乗り超ゆるなり」 | OK |
| SY3-P34 | 触の生滅を知ることで、苦の集を断つ条件が整う | 嫌な感触が来たとき「触は縁起、我に非ず」と観る | 触の制御 | 「触の生ずるを如実に知り、触の滅するを如実に知る者は、苦の集を断つ」 | OK |
| SY3-P35 | 六入相応の地図——六根·六境·触受愛取·内空外空·根律儀·離貪解脱 | 就寝前、感覚経験のうち一つに「縁起、空、離貪」の三語を当てはめて眠る | 総括 | 「眼は無常なり……意は無常なり。此の道によりて厭離し、離貪し、解脱すべし」 | 要約 |
