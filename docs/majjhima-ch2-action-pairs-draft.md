| MM2-P02 | 身念処の入口——内に長息·短息を知る | 朝、五分間、長い息·短い息を「知る」だけに徹する | 身·呼吸 | 「内に長息を知り、長息と知る。短息を知り、短息と知る」 | OK |
| MM2-P03 | 立·歩·座·臥——すべての姿勢に正知を伴う | 今日、立つ·座る·歩く動作の一つに身体感覚を意識する | 身·姿勢 | 「此の身を、立てて、歩いて、座して、臥して、すべての姿勢に、知りをもって伴い、正知をもって伴う」 | OK |
| MM2-P04 | 正知——行為の目的を見抜き、無益な行為を避ける | 今日、一つの行動の前に「これは何のためか」と問う | 身·正知 | 「正知をもって、行為の目的を見抜き、無益な行為を避ける」 | OK |
| MM2-P05 | 此の身は皮·肉·筋·骨……執着の対象ではない | 身体への過剰な執着が来たら、不浄の集まりと見る | 身·不浄 | 「此の身の中の皮を、肉を、筋を、骨を……如実に観察する」 | OK |
| MM2-P06 | 地·水·火·風——此の身も外の世界も同じ元素 | 身体の感覚を「地·水·火·風のどれか」と見分ける | 身·四界 | 「此の身に、地界、水界、火界、風界があることを、内に、外に、内外に観察する」 | OK |
| MM2-P07 | 死想——此の身も死ぬべきもの | 身体の健やかさに「これも無常」と一瞬付け加える | 身·死想 | 「此の身も、あらゆる方向の死体と同じく、死ぬべきものと観察する」 | OK |
| MM2-P08 | 身念処は内·外·内外——渇愛の除い去るに依りて修する | 自分の身体感覚を観たあと、他者の動きにも同じ構造を見る | 身 | 「内に此の身に身の念処を、熱情に、正知に、念に、渇愛の除い去るに依りて修する」 | OK |
| MM2-P09 | 受念処——苦受·楽受·不苦楽受を如実に知る | 感情が動いたとき、三受のどれかと名づける | 受 | 「内に受に受の念処を、熱情に、正知に、念に、渇愛の除い去るに依りて修する」 | OK |
| MM2-P10 | 心念処——貪ある心·貪なき心を如実に知る | 心の状態を「貪·瞋·散乱の有無」と観る | 心 | 「貪ある心は、貪ある心と知る。貪なき心は、貪なき心と知る」 | OK |
| MM2-P11 | 法念処——五蓋を如実に知る | 今日心を曇らせた蓋を一つ「蓋」と名づける | 法·五蓋 | 「五蓋あり。何ぞや。貪欲の蓋、瞋恚の蓋、惛眠の蓋、掉挙·恨の蓋、疑の蓋是なり」 | OK |
| MM2-P12 | 法念処——七覚支を如実に知る | 七覚支のうち「念」または「擇法」を一つ意識する | 法·七覚支 | 「七覚支あり。念覚支、擇法覚支、精進覚支、喜覚支、軽安覚支、定覚支、捨覚支是なり」 | OK |
