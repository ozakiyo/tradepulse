## MN 1 根本法門経

| id | 観察 | 行動 | 節 | quote（南伝照合） | 照合 |
|---|---|---|---|---|---|
| MM1-P01 | 諸法の根本は「取る」と「喜ぶ」——地から涅槃まで同じ構造 | 朝、今日執着しやすい対象を一つ挙げ、「取る/喜ぶ」を観察する | 導 | 「我、汝等のために、諸法の根本法門を説く」 | OK |
| MM1-P02 | 聞なき凡夫は聖法を学ばず、顛倒想で対象を認める | 今日、確信の根拠が「自分の遍知」か一度問う | 凡夫 | 「聞なき凡夫は、聖者を承認せず、聖法を熟知せず、聖法を導とせず」 | OK |
| MM1-P03 | 凡夫は地を地と想し、「我は地なり」と想し、地を喜ぶ | 身体・場所への「これは私」と感じる瞬間、一度手放す | 凡夫·地 | 「地を地と想し……『我は地なり』と想し、地を喜ぶ」 | OK |
| MM1-P04 | 見聞覚知の対象も同じ——「我は見なり」と取れば苦が続く | 今日見た・聞いた情報に「私の正しさ」を載せない | 凡夫·見聞 | 「見を見と想し……『我は見なり』と想し、見を喜ぶ」 | OK |
| MM1-P05 | 有学の比丘は地を正しく知るが、「我は地なり」とは想しない | 修行中の自分に「まだ取る所がある」と正直に認める | 有学 | 「有学の比丘は地を正しく知るが、『我は地なり』と想すべきではなく、地を喜ぶべきではない」 | OK |
| MM1-P06 | 阿羅漢は遍知し、貪瞋痴を除却したゆえに喜ばない | 今日、執着が弱まった瞬間を「喜ばない知」と認める | 阿羅漢 | 「阿羅漢は……地を喜ばない。なぜなら、彼はこれを遍知し、貪欲・瞋恚・愚痴を除却したから」 | OK |
| MM1-P07 | 如来は喜び（nandī）を苦の根源と知る——有→生→老死 | 快い経験の裏に「取る/喜ぶ」がないか一瞬見る | 如来 | 「如来は、喜びが苦の根源であることを知り、有より生、生より老死が来ることを知る」 | OK |
| MM1-P08 | 正見は対象を否定することではなく、顛倒なく知ること | 今日、一つの対象を「ありのまま」に見る練習を一つする | 有学 | 「地を正しく知る（paṭhaviṃ abhijānāti）」 | OK |
| MM1-P09 | 涅槃まで「我は涅槃なり」と取れば、解脱さえ概念になる | 「悟り」「正しい」というラベル自体に執着していないか問う | 凡夫·涅槃 | 「涅槃を涅槃と想し……『我は涅槃なり』と想し、涅槃を喜ぶ」 | OK |
| MM1-P10 | 根本法門は軽く聞く経ではない——善く念じて聞け | 今日のペアを一つ、声に出して読み返す | 導 | 「善く念じて聞け。我、今説く」 | OK |

## MN 2 一切漏経

| id | 観察 | 行動 | 節 | quote | 照合 |
|---|---|---|---|---|---|
| MM1-P11 | 漏尽は知と見によってのみ——不知不見ではない | 今日、体験を「知った/推測した」で分ける | 導 | 「我、知と見によって諸漏の尽き有り、不知不見によって有らずと説く」 | OK |
| MM1-P12 | 不正作意で未生の漏が起き、已生の漏が増す | 反芻・未来の心配が来たら「不正作意」と名づける | 作意 | 「不正作意の故、未生の諸漏生起し、已生の諸漏増長す」 | OK |
| MM1-P13 | 正作意で未生の漏は起きず、已生の漏は捨てられる | 苦・集・滅・道の一つに意識を向ける | 作意 | 「正作意の故、未生の諸漏生起せず、已生の諸漏捨て去られ」 | OK |
| MM1-P14 | 漏は七つの門から捨てられる——見·護·用·忍·避·除·修習 | 今日は七つのうち「護（根門）」を一つ意識する | 七法 | 「漏、見によりて捨て去られ……修習によりて捨て去られる」 | OK |
| MM1-P15 | 見による漏尽——不正作意から六見・身見が生じる | 「過去の私はどうだったか」と未来の私を問う思考を止める | 見 | 「不正作意の故、六見のいずれかの見生起す……我に我ありと見る」 | OK |
| MM1-P16 | 見の結縛——身見・疑・戒禁取の三結 | 今日の確信が「戒の形式」だけに縛られていないか問う | 見 | 「見結に縛られ、聞なき凡夫は生老病苦から解脱せず」 | OK |
| MM1-P17 | 防護——眼根を護らねば憂の漏が起きる | スマホを開く前に「眼根を護る」と一呼吸置く | 護 | 「眼根を護らねば、憂悲恼の諸漏生起す。護れば生起せず」 | OK |
| MM1-P18 | 受用——衣食床座医薬を正しく受ける | 食事を「肥悦・虚飾のためでなく、梵行の助けのため」と確認する | 用 | 「衣・食・床座・病薬の四事を正しく受く」 | OK |
| MM1-P19 | 除遣——已生の欲念・嗔念を容受せず遠ざける | 嗔が起きたら、一度声に出さず、除遣の一歩を踏む | 除 | 「已生の欲念を容受せず、捨て除き遠ざけ絶滅す」 | OK |
| MM1-P20 | 修習——七覚支を離染離欲の方向に修する | 今日、七覚支のうち「念」または「擇法」を一つ意識する | 修習 | 「念覚支・擇法覚支……を修し、離・離染・滅尽・出離に向かわしむ」 | OK |
| MM1-P21 | 聖弟子は応作意を作意し、不応作意を作意しない | 今日「すべき観察」と「すべきでない反芻」を一つずつ決める | 聖弟子 | 「応作意の法を作意し、不応作意の法を作意せず」 | OK |
| MM1-P22 | 正作意四諦で三結が捨てられる——身見の対治 | 一つの苦について「これは苦諦」と静かに認める | 四諦 | 「『此是苦・此是集・此是滅・此是道』と正作意すれば、三結捨て去る」 | OK |

## MN 11 師子吼小経

| id | 観察 | 行動 | 節 | quote | 照合 |
|---|---|---|---|---|---|
| MM1-P23 | 師子吼——此の教団にのみ四沙門（四果）がある | 今日、自分の修行を「形式」ではなく「果」に結びつけて問う | 師子吼 | 「汝等、師子吼を為すべし。『此の教団にのみ沙門あり、第二・第三・第四の沙門あり。他の教えに沙門なし』」 | OK |
| MM1-P24 | 外道も信・戒・敬愛を称する——差は取の遍知にある | 他者の良い点を認めつつ、見取・我見取を手放す | 四法 | 「如来は一切の取を遍知す。欲取・見取・戒取・我見取を遍知す」 | OK |
| MM1-P25 | 究竟の目標は一つ——貪瞋痴渴愛執取のない者が至る | 今日の目標が「勝つこと」ではなく「執取の減ること」か問う | 問答 | 「究竟の目標は一つのみ。貪欲ある者は至らず、貪欲なき者は至る」 | OK |
| MM1-P26 | 有見と無有見——どちらにも執着すれば諍いが起きる | 議論で「存在する/しない」の極端に寄らない | 二見 | 「有見と無有見、この二見あり。執着・近着・附着する者は諍う」 | OK |
| MM1-P27 | 二見の集滅味患離を知らねば、戲論（papañca）が止まらない | 今日、見解を証明したい衝動を「戲論」と名づける | 二見 | 「二見の集・滅・味・患・離を如実知らねば、戲論を好み、諍う」 | OK |
| MM1-P28 | 四取——欲取・見取・戒取・我見取 | 今日の執着が四取のどれか一つを特定する | 四取 | 「四取あり。欲取、見取、戒取、我見取是なり」 | OK |
| MM1-P29 | 取の因は愛——愛の因は受、受の因は触 | 執着が来たら「触→受→愛→取」の流れを一つ辿る | 縁起 | 「四取は愛を縁とし、愛は受を縁とし、受は触を縁とす」 | OK |
| MM1-P30 | 無明を断ち明を生ずれば、四取を執らず、涅槃を自証する | 夜、今日の無明（迷い）を一つ認め、執取を手放して眠る | 結 | 「無明を断ち明を生ず。取を執らず、挂慮なく、涅槃を自ら証知す」 | OK |
| MM1-P31 | 正語——諍いと戲論を止める | 今日、教義の優劣を争う言葉を一度止める | 二見 | 「常に人と諍い、戲論を好む者は苦から解脱せず」 | OK |
| MM1-P32 | 対人——不諍論者だけが究竟に至る | 反論したくなったとき、相手の利益を一つ考えてから話す | 問答 | 「人と諍わざる者は究竟の目標に至る」 | OK |
| MM1-P33 | 精進·正念——善説善調の法と律に依る | 今日学んだ三経のうち、一節をメモし明日も反芻する | 結 | 「善説・善調の法と律は、出離・止息をもたらし、等正覚者の説なり」 | OK |
| MM1-P34 | 対治——欲取だけ知り我見取を知らぬ「遍知」は不満 | 自分の修行が「好みの部分」だけで終わっていないか問う | 四取 | 「欲取のみ遍知し、我見取を遍知せず——是れ円満の遍知に非ず」 | OK |
| MM1-P35 | 振り返り——第1章の地図：見解→漏→取 | 就寝前、今日「取ったもの」を一つ書き、明日手放す | 総括 | 「見解を正し、漏を塞ぎ、取を離れよ」 | 要約 |
