# チーム J — bitbank 現物マルチ銘柄トラリピ

**G-CFX**（GMO暗号FXレンジ）の代替ではなく、**bitbank 現物・買いのみトラリピ**を複数銘柄で回すチームです。

## コンセプト

| 項目 | 内容 |
|------|------|
| 取引所 | bitbank **現物**（API） |
| 方向 | **買いのみ**（ロング偏り許容） |
| ロスカット | **なし**（現物） |
| ロット | **1段あたり最低 JPY**（既定 1,000円相当）— API最小だけでは利幅が実質ゼロ |
| 銘柄選定 | **1セット資金↓ × トラップ幅↓** の銘柄を自動優先（BTC固定ではない） |
| トラップ | **日足**ベースの幅・本数（ATR 等で調整） |
| 銘柄 | API で取得した **現物取引可能ペア** から選択 |
| 同時銘柄数 | 開始時は **上位2銘柄** |

### BTC 長期保有（保護しつつトラップ可）

口座にある **0.20263447 BTC** は長期保有用として保護し、TEAM-J では **この数量までは売却しません**。  
一方で `btc_jpy` 自体は候補に含め、JPY からの新規買いトラップは可能です。

| 設定 | 既定値 |
|------|--------|
| `BTC_RESERVE_AMOUNT` | `0.20263447` |
| `J_EXCLUDE_PAIRS` | 空（既定では除外なし） |

- 売却・トレール時は `jGetTradableCoin_` で **free − 保護分** のみ使用
- つまり、既存の `0.20263447 BTC` は残したまま、追加で買った BTC 分だけをトラップ売却します
- メニュー「6. BTC長期保有の確認」で口座残高と保護分を確認可能

## 銘柄ローテーション

### 状態遷移

```
[アクティブ] 日足レンジ内 → 買いトラリピ稼働
     ↓ 日足トラップ外れ or トレンド
[休眠] 新規買い停止・現物は放置
     ↓ 他銘柄へローテ
[他銘柄アクティブ] …
     ↓ 旧銘柄: 各ロットの売り指値で全量約定（A.決済完了）
[B. 再開] 日足レンジ OK → 買いグリッド新規スタート
```

### ① 旧銘柄の現物（確定）— 2段階再開

**外れ・トレンド時**: 新規買い指値を止める（**休眠**）。約定済みロットは state に保持。

**再開は2段階**（同時ではない）:

| 段階 | 条件 | 動作 |
|------|------|------|
| **A. 決済** | **価格が戻った** — 残っていたトラップ買いロットが、**それぞれの売り指値（利確価格）で約定したとき**（全ロット消化） | 休眠の決済完了。買いグリッドはまだ張らない |
| **B. 再開** | **日足レンジ判定 OK**（②のレンジモード） | **買いグリッドを新規スタート** |

- 休眠中も **約定済みロットごとの売り指値／トレール売りは継続**（チームA `bbManageGridTrails_` 相当）
- 日足の高値・安値「内に終値が戻った」だけでは A にならない
- A 完了後、B が NG → 現物なし・グリッドなしで待機

## ② 日足トラップ外れ・トレンド（実装案）

チームA の 1H レジーム（`Regime.gs`）を **日足** に置き換えた判定を使う（閾値は検証で調整）。

### 日足レンジ（トラリピ可能）

過去 **20日** の高値・安値で:

| 条件 | 既定案 |
|------|--------|
| 日足レンジ幅 | 高安幅 / 中値 ≤ **15%**（暗号向けに G-CFX より緩め） |
| ER（効率比） | ≤ **0.30** |
| ADX | ≤ **25** |
| EMA20/50 クロス | 20日で **≥ 4回**（往復多い＝レンジ） |

**レンジスコア ≥ 2** かつ **トレンドスコアより大** → レンジ

### 日足トレンド（ローテ対象）

| 条件 | 既定案 |
|------|--------|
| ER | ≥ **0.30** |
| ADX | ≥ **25** |
| EMA クロス | ≤ **2回** |

**トレンドスコア ≥ 2** かつ **レンジより大** → トレンド → **休眠＋他銘柄へ**

### 日足トラップ外れ（買いのみ）

日足レンジの **下限（refDailyLow）** を、確定日足終値が **下抜け**:

```
close < refDailyLow × (1 - bufferPct)   bufferPct 既定 0.3%
```

上抜けは買いのみのため利確方向。外れ判定は **下抜けのみ**（トラップ崩壊）。

### 次銘柄の選び方（自動選定）

**方針**: 日足レンジ内で、**日中変動 ÷ trapStep（変動倍率）が大きい銘柄**を優先する。同率なら必要資金が少ない順。

1. API 現物ペア一覧から JPY 建てを対象
2. いま **アクティブでない** 銘柄（休眠中で現物残ありは除外）
3. 上記 **日足レンジ** を満たすもの
4. **変動倍率 (`moveStepRatio`) が高い順** に並べる

```
日中変動     = 過去5日（確定日足）の (高値−安値) 平均
変動倍率     = 日中変動 ÷ trapStep
              例: 日中2円 / 間隔0.5円 → 4.0x（1日で利確条件に届きやすい）
```

| 優先度 | 指標 | 理由 |
|--------|------|------|
| 高 | **変動倍率が大きい** | trapStep 比で動く → 利確しやすい |
| 中 | **必要資金が小さい** | 同じ口座で2銘柄運用 |
| 中 | **日足レンジ内の本数が多い** | レンジ内でのトラップ回数↑ |
| 低 | BTC 等の高単価銘柄 | 間隔が大きく回転しにくい |

5. 口座 JPY の **80%以内** に収まるよう、上から **2銘柄まで** 割り当て

**1段ロット**: 初版は `MIN_LEVEL_JPY = 1000`（API `unit_amount` だけだとアルトは1段数十円で利幅ゼロ）  
**最低本数**: `MIN_GRID_LEVELS = 4` を目安に、日足レンジが許す限り 1〜2本で終わりにくいよう trapStep を圧縮

### 選定ランキングの確認

```bash
# 1段1000円相当・日足レンジOKのみ（GAS 想定と同じ）
npm run team-j:capital:rank

# 全銘柄の資金一覧
npm run team-j:capital
```

## 手数料・取引コスト（GAS: `TradingFees.gs`）

出典: [bitbank 手数料](https://bitbank.cc/docs/fees/)（**2026年2月2日**時点）

### 取引所・現物売買

| ペア | メイカー（指値） | テイカー（成行） |
|------|------------------|------------------|
| **BTC/JPY** | **0%** | **0.10%** |
| その他 JPY 建て | **-0.02%**（リベート） | **0.12%** |

- TEAM-J は **指値のみ** → 想定は **メイカー**
- アルトのメイカー **-0.02%** は約定ごとに **0.02% 還元**（1ラウンドで約 +0.04%）
- **資金計算の保守側**は `FEE_ROLE_FOR_CAPITAL=taker`（Config 既定）
- **利益見積**は `FEE_ROLE_FOR_PROFIT=maker`（Config 既定）

### 入出金（参考 — トラリピ運用では原則不要）

| 種別 | 手数料 |
|------|--------|
| 日本円入金 | 無料（銀行振込手数料は利用者負担） |
| 日本円出金 | 550円（3万未満）/ 770円（3万以上） |
| 暗号資産入金 | 無料 |
| 暗号資産出金 | 銘柄別固定（例: BTC 0.0006, TRX 3, DAI 10） |
| 口座開設・維持 | 無料 |

### GAS メニュー

スプレッドシートを開くと **チームJ Bot** メニュー:

1. **手数料一覧** — 公式 rates サマリー
2. **銘柄別手数料・1R利益** — 1トラップラウンドの純利益（maker/taker）
3. **銘柄選定ランキング** — 手数料込み selectScore
4. **口座予算で自動選定** — `PAPER_JPY` 内で最悪グリッドが収まる銘柄

## ③ 必要資金・同時銘柄数

```
1銘柄あたり = Σ (買値_i × 1段数量 × 1.02)   i = 0 .. levels-1
同時銘柄数   = floor( 口座JPY / 1銘柄あたり )   ※余裕20%推奨
```

- **1段数量**: 初版は **`MIN_LEVEL_JPY = 1000`**
- **グリッド本数・間隔**: 日足20日レンジ内。資金・1R利益は **`TradingFees.gs`** で手数料込み計算
- **検証用の初期資金**は下記コマンドで算出してから決める

- **BTC メインではない** — 1セット≈2,000円・間隔32万円級で、最小ロットでも回転しにくい

## 急落 STOP（チームA との関係）

**TEAM-J ではチームA 専用の 1H −1.5% STOP は原則不要**（別途入れない）。

| イベント | TEAM-J の動き |
|----------|----------------|
| 日足トラップ外れ / トレンド | **休眠** — 新規買い指値キャンセル、ローテ |
| 約定済みロット | 売り指値／トレールは **休眠中も継続**（A.決済） |

チームA の STOP は「レンジ判定のまま **1H だけ急落**」した瞬間に **全指値キャンセル** する安全弁。TEAM-J は **日足ベースで外れた時点で休眠** するため、役割が重なる。

**例外**: アクティブ銘柄で **日足はレンジのまま 1H だけ急落** した場合、休眠トリガーが遅れる可能性あり。必要なら後から **アクティブ銘柄のみ** 1H ショックキャンセルを追加検討。
