# チームG — bitbank レンジ（買いのみ・10銘柄）

> **現在は検証停止（既定）** — GAS負担軽減のため `VALIDATION_PAUSED=true`。実践は **G-CFX**（暗号資産FX）を使用。再開時は `VALIDATION_PAUSED=false`。

日足がレンジ、かつ1時間足も日足レンジ内でレンジのとき、**1H下限付近で買い**・**1H幅×TP_RATIOで売り（利確）**します。  
**5分足の終値**が1H下限を下抜けたら**半分損切**、日足下限を下抜けたら**残り損切**します（現物のためショートなし）。

## 対象銘柄（既定10）

`btc_jpy`, `eth_jpy`, `xrp_jpy`, `sol_jpy`, `doge_jpy`, `link_jpy`, `ada_jpy`, `ltc_jpy`, `bnb_jpy`, `dot_jpy`

## セットアップ

1. **新しい GAS プロジェクト**と**専用スプレッドシート**を作成（チームBとは別）
2. 本フォルダの `.gs` と `appsscript.json` をエディタにコピー
3. スクリプトプロパティ（メニュー「8. 既定プロパティ設定」でも初期化可）

| キー | 例 | 説明 |
|------|-----|------|
| `BITBANK_API_KEY` | （必須） | bitbank API |
| `BITBANK_API_SECRET` | （必須） | |
| `META_SPREADSHEET_ID` | （推奨） | メタ層SSのID（`META_統合レポート` へ日次送信） |
| `DRY_RUN` | `true` | **デモ（紙トレ）**。本番は `false` |
| `PAPER_JPY` | `500000` | 紙トレ初期JPY |
| `G_PAIRS` | 省略可 | カンマ区切りで銘柄を絞る |
| `G_MAX_JPY_PER_PAIR` | `50000` | 1銘柄あたりの最大投入 |
| `G_MAX_OPEN_POSITIONS` | `7` | 同時保有銘柄数 |
| `G_TOUCH_PCT` | `0.12` | 1H上下限のタッチ幅（%） |
| `G_DAILY_RANGE_MAX_PCT` | `12` | 日足レンジ幅の上限（%） |
| `G_H1_RANGE_MAX_PCT` | `4` | 1Hレンジ幅の上限（%） |
| `G_TP_RATIO` | `0.55` | 利確位置（0.5=中間, 0.667=2/3, 1.0=反対端） |
| `G_PARTIAL_STOP_RATIO` | `0.5` | 1H損切時の決済比率（残りは日足損切） |

4. スプレッドシートを開き、メニュー **チームG Bot → 6. シート初期化**
5. **7. 接続テスト**（初回はエディタから `gTestConnection` 実行で権限許可）
6. **2. 1回だけ実行** で動作確認
7. **12. META接続テスト**（`META_SPREADSHEET_ID` 設定後）
8. **10. 日次レポートトリガー設置**（毎日6時 → META集計、メタ層7時総括の前）
9. 問題なければ **3. 5分トリガーを設置**（`VALIDATION_PAUSED=false` のときのみ）

### 検証停止中（現在）

- 5分・日次トリガーは **即スキップ**（bitbank API を呼ばない）
- 既存トリガーがある場合はメニュー **「4. トリガーを削除」**「11. 日次レポートトリガー削除」で外すと GAS 負担がさらに減ります
- 手動の「2. 1回だけ実行」は停止フラグに関係なく動きます（テスト用）

## シート

- `G_運用ログ` — **売買時**または**日足/1Hレンジが変わったとき**のみ記録
- `G_売買履歴` — 買い・売り（デモ含む）※売買のたびに記録

## ロジック概要

```
日足レンジ（過去20日程度の高安幅 ≤ 12%）
  └ 1Hレンジ（48本・日足内・幅 ≤ 4%）
       ├ 5分終値 ≈ 1H下限 → 買い（DRY_RUN時は紙・数量は最小単位の2倍）
       ├ 保有中 & 5分終値 ≈ 1H幅×TP_RATIO → 売り（利確）
       ├ 保有中 & 5分終値 < 1H下限 → 半分売り（1H損切）
       └ 保有中 & 5分終値 < 日足下限 → 残り売り（日足損切）
```

## 注意

- 10銘柄はBTCと相関が高く、分散効果は限定的です
- `DRY_RUN=true` では注文は出さず、スプレッドシートと `G_STATE` に紙残高を記録します
- 本番移行前に2週間以上のデモ運用を推奨
- APIキーはチームBと共有可能ですが、**投入上限は別プロパティで管理**してください
