# BITBANK × Google Apps Script（BTC 1/10 試験）

相場環境に応じて自動切替:

| 環境 | 操作 |
|------|------|
| **レンジ** | トラリピ（フル） |
| **中立** | トラリピ（縮小） |
| **トレンド** | スイング（現物ロング） |
| **急変** | **STOP**（全注文キャンセル） |

**通知**: **相場環境が変わったときだけ LINE**（tradePulseNode と同じトークン・ユーザーID）。  
**売買履歴・損益**: スプレッドシートの「運用ログ」「売買履歴」で管理（メール通知は使いません）。

**1/10 はロット（BTC 数量）のみ**。幅は本番どおり 50,000円です。

| 項目 | 本番 | 試験（既定） |
|------|------|-------------|
| トラリピ幅 | 50,000円 | **50,000円** |
| 1本あたりロット | **0.001 BTC** | **0.0001 BTC** |
| 買い本数（フル） | 8本 | **8本** |
| スイング | 0.001 BTC | **0.0001 BTC** |

| ファイル | 内容 |

## セットアップ

### 1. BITBANK API キー

1. [bitbank.cc](https://bitbank.cc) → 設定 → API
2. **現物取引** 権限を付与（読み取り + 注文）
3. API Key / Secret を控える

### 2. Google Apps Script プロジェクト

1. Google スプレッドシートを新規作成
2. **拡張機能** → **Apps Script**
3. `bitbank-gas/` 内の `.gs` ファイルをすべてコピー
4. **プロジェクトの設定** → タイムゾーン **Asia/Tokyo**
5. メニュー **BITBANK Bot** → **6. シート初期化**（運用ログ・売買履歴）

### 3. スクリプトプロパティ

**プロジェクトの設定** → **スクリプト プロパティ**:

| キー | 値（例） |
|------|----------|
| `BITBANK_API_KEY` | （必須） |
| `BITBANK_API_SECRET` | （必須） |
| `LINE_CHANNEL_ACCESS_TOKEN` | tradePulse と同じ（環境変化時のみ） |
| `LINE_USER_ID` | 同上 |
| `DRY_RUN` | `true`（最初は必ず true） |

任意の調整:

| キー | 既定 | 説明 |
|------|------|------|
| `TORARIPI_WIDTH_JPY` | 50000 | トラリピ幅（円） |
| `BTC_PER_LEVEL` | 0.0001 | 買い1本あたりの BTC 数量 |
| `SWING_BTC` | 0.0001 | スイングの BTC 数量 |
| `GRID_LEVELS` | 8 | 買い本数（フル） |
| `SHOCK_MOVE_PCT` | 1.5 | 急変判定（1H変動%） |

### 4. 初回テスト

1. スプレッドシートを開き直す → メニュー **BITBANK Bot**
2. `bbSetupDefaultProperties` を Apps Script エディタから1回実行（任意）
3. **2. 1回だけ実行（テスト）** → 「運用ログ」シートに1行追加、ログ確認
4. 環境が変われば LINE（`DRY_RUN=true` のときはログのみ）
5. 問題なければ `DRY_RUN` を `false` に変更
6. **3. 5分トリガーを設置**

## スプレッドシート

| シート | 内容 |
|--------|------|
| **運用ログ** | 5分ごとの環境・操作・価格・残高（自動追記） |
| **売買履歴** | 注文実行時に自動追記（損益集計は別途ユーザー管理） |

## 資金の目安（ロット 0.0001）

BTC 1,200万円想定: 0.0001 BTC ≒ 約1,200円/本 × 8本 ≒ 約1万円＋急落バッファ。

| 区分 | 金額 |
|------|------|
| 推奨 | **3〜5万円**（JPY）＋ バッファ |
| 本番ロット 0.001 に上げるとき | 上記の **約10倍** の JPY 余力 |

---

## 注意

- **最初は必ず `DRY_RUN=true`** でログだけ確認してください。
- 本番は自己責任。急落時は STOP しますが、**全リスクを防げるわけではありません**。
- GAS の実行時間制限（6分）内で動くよう、注文本数は控えめです。

---

## tradePulseNode との関係

- **tradePulseNode** … USD/JPY・BTC の環境監視、**環境変化時のみ LINE**（サーバー `/opt/tradePulseNode`）
- **bitbank-gas** … BITBANK 実注文＋同じ LINE トークンで BTC 環境変化を通知

両方とも「環境が変わったときだけ LINE」。日々の売買・損益はスプレッドシートでまとめてください。
