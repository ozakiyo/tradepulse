# BITBANK × Google Apps Script — **チームA**

**資金配分はメタ層**（`bitbank-gas-meta/`・Auto 責任）が決定します。

相場環境に応じて自動切替（トラリピ / スイング / STOP）:

| 環境 | 操作 |
|------|------|
| **レンジ** | トラリピ（フル） |
| **中立** | トラリピ（縮小） |
| **トレンド** | スイング（現物ロング） |
| **急落**（1H −1.5%超） | **STOP**（全注文キャンセル） |
| **急騰**（1H +1.5%超） | **トレンド/スイング**（通常判定 or トレンドへ寄せ） |

**通知**: **相場環境が変わったときだけ LINE**（tradePulseNode と同じトークン・ユーザーID）。  
**売買履歴・損益**: スプレッドシートの「運用ログ」「売買履歴」で管理（メール通知は使いません）。

**1/10 はロット（BTC 数量）のみ**。**各トラップの間隔**は本番どおり 50,000円（固定）。**上限（現在値）～下限（どこまで下に並べるか）** だけが ATR で変わり、本数も増減します。

| 項目 | 本番 | 試験（既定） |
|------|------|-------------|
| 各トラップ間隔 | 50,000円 | **50,000円**（固定） |
| 1本あたりロット | **0.001 BTC** | **0.0001 BTC** |
| 買い本数（フル） | 最大30本 | **最大30本**（相場で減ることあり） |
| スイング | 0.001 BTC | **0.0001 BTC** |

## セットアップ

### 1. BITBANK API キー

1. [bitbank.cc](https://bitbank.cc) → 設定 → API
2. **現物取引** 権限を付与（読み取り + 注文）
3. API Key / Secret を控える

### 2. Google Apps Script プロジェクト

1. Google スプレッドシートを新規作成
2. **拡張機能** → **Apps Script**
3. `bitbank-gas/` 内の `.gs` ファイルをすべてコピー
4. **プロジェクトの設定** → タイムゾーン **Asia/Tokyo**
5. メニュー **BITBANK Bot** → **6. シート初期化**（4シート: 運用ログ・売買履歴・日次集計・2週間試験）
6. [2週間試験チェックリスト](docs/2週間試験チェックリスト.md) に沿って Day 0 から開始

### 3. スクリプトプロパティ

**プロジェクトの設定** → **スクリプト プロパティ**:

| キー | 値（例） |
|------|----------|
| `BITBANK_API_KEY` | （必須） |
| `BITBANK_API_SECRET` | （必須） |
| `LINE_CHANNEL_ACCESS_TOKEN` | tradePulse と同じ（環境変化時のみ） |
| `LINE_USER_ID` | 同上 |
| `DRY_RUN` | `true`（最初は必ず true） |

任意の調整:

| キー | 既定 | 説明 |
|------|------|------|
| `TORARIPI_WIDTH_JPY` | 50000 | **各トラップの間隔**（円・固定） |
| `TORARIPI_ATR_REF_PCT` | 1.0 | ATR%の基準（仕掛け下限の伸縮） |
| `TORARIPI_RANGE_MIN_FACTOR` | 0.75 | 下限幅の最小倍率（本数が減る） |
| `SWING_TRAIL_ACTIVATE_PCT` | 0.5 | スイング: 建値+0.5%でトレール開始 |
| `SWING_TRAIL_CALLBACK_PCT` | 0.25 | スイング: 高値から-0.25%で利確 |
| `SWING_MAX_PROFIT_PCT` | 0 | スイング上限利確%（0=トレールのみ） |
| `BTC_PER_LEVEL` | 0.0001 | 買い1本あたりの BTC 数量 |
| `SWING_BTC` | 0.0001 | スイングの BTC 数量 |
| `GRID_LEVELS` | 30 | 買い本数の上限（フル・相場で減る） |
| `SHOCK_MOVE_PCT` | 1.5 | 急変判定（1H変動%） |

### 4. 初回テスト

1. スプレッドシートを開き直す → メニュー **BITBANK Bot**
2. `bbSetupDefaultProperties` を Apps Script エディタから1回実行（任意）
3. **2. 1回だけ実行（テスト）** → 「運用ログ」に1行追加。**詳細** に `ローソク不足` と出ないこと（55本以上で ADX/ER が入る）

**ローソク不足** … 1時間足が55本未満のとき。`BitbankApi.gs` は最大5日分を遡って取得するよう修正済み（次回実行から解消）。
4. 環境が変われば LINE（`DRY_RUN=true` のときはログのみ）
5. 問題なければ `DRY_RUN` を `false` に変更
6. **3. 5分トリガーを設置**

## 資金の目安（ロット 0.0001）

BTC 1,200万円想定: 0.0001 BTC ≒ 約1,200円/本。最大30本・間隔5万なら下限まで約145万円下に並ぶため、**実際の本数はATRで減り、JPY残高でも打ち止め**になります。

| 区分 | 金額 |
|------|------|
| 推奨 | **3〜5万円**（JPY）＋ バッファ |
| 本番ロット 0.001 に上げるとき | 上記の **約10倍** の JPY 余力 |

## 注意

- **最初は必ず `DRY_RUN=true`** でログだけ確認してください。
- 本番は自己責任。急落時は STOP しますが、**全リスクを防げるわけではありません**。
- GAS の実行時間制限（6分）内で動くよう、注文本数は控えめです。

## tradePulseNode との関係

| 担当 | 銘柄 | 内容 |
|------|------|------|
| **tradePulseNode**（サーバー） | **USD/JPY のみ** | 環境監視・LINE |
| **bitbank-gas**（本 GAS） | **BTC のみ** | 監視・売買・LINE・スプレッドシート |

BTC の LINE は **GAS だけ** から送ります（tradePulse の BTC 監視は既定でオフ）。  
LINE トークンは同じでも構いません。日々の売買・損益はスプレッドシートでまとめてください。
