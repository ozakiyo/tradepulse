# 日次集計シート — 列定義

試験運用（DRY_RUN → 本番）の **KPI は日次利益より環境精度・ルール遵守** です。  
毎日 5 分、週 1 回 15 分の更新を想定しています。

---

## シート構成（全4枚）

| シート名 | 更新 | 用途 |
|----------|------|------|
| **運用ログ** | 自動（5分） | GAS の環境・残高スナップショット |
| **売買履歴** | 自動＋手動 | 約定・損益の詳細 |
| **日次集計** | 手動（毎日） | 1日の振り返り・KPI |
| **2週間試験** | 手動（随時） | 試験期間の合格条件チェック |

メニュー **BITBANK Bot → 6. シート初期化** で上記4枚を一括作成できます。

---

## 日次集計 — 列定義（A〜U）

| 列 | ヘッダー | 入力 | 説明・記入例 |
|----|----------|------|--------------|
| **A** | 日付 | 手動 | `2026-05-22`（JST の取引日） |
| **B** | フェーズ | 手動 | `DRY_RUN` または `本番` |
| **C** | 環境切替回数 | 手動 | 運用ログで環境列が変わった回数（目安: 0〜3回/日） |
| **D** | 終了時環境 | 手動 | その日最後の環境（例: `レンジ` `トレンド（アップ）`） |
| **E** | 取引回数 | 数式可 | 売買履歴のその日の行数（DRY_RUN 時は 0 でも可） |
| **F** | 買い回数 | 数式可 | 売買履歴「買い」の件数 |
| **G** | 売り回数 | 数式可 | 売買履歴「売り」の件数 |
| **H** | 実現損益(円) | 手動 | 確定した損益合計（本番のみ。DRY_RUN は `-` 可） |
| **I** | 手数料(円) | 手動 | bitbank 手数料の合計（目安: 約 0〜数百円/試験ロット） |
| **J** | 純損益(円) | 数式 | `=H2-I2` |
| **K** | 含み損益(円) | 手動 | 終値時点の含み（BTC 保有時のみ） |
| **L** | JPY残高(終値) | 手動 | 運用ログのその日 **最終行** の JPY 残高 |
| **M** | BTC残高(終値) | 手動 | 同上 BTC 残高 |
| **N** | BTC終値 | 手動 | 運用ログ最終行の BTC 価格 |
| **O** | 24h変動(%) | 手動 | 前日比 or 24h High-Low（環境判定の検証用） |
| **P** | 環境精度 | 手動 | `◎` 合致 / `△` 一部ズレ / `×` 明らかに不一致 |
| **Q** | 環境精度メモ | 手動 | 例:「レンジ判定だが 1H で ±2% 往復」 |
| **R** | LINE通知回数 | 手動 | tradePulse + GAS 合計（環境変化のみ） |
| **S** | ルール遵守 | 手動 | `OK` / `NG`（手動介入・設定変更があったら NG） |
| **T** | 日次損失上限 | 手動 | `OK`（-2,000円以内）/ `NG` / `-`（DRY_RUN） |
| **U** | メモ | 手動 | 気づき・翌日やること1つ |

### 試験期間の KPI 優先順位

1. **環境精度**（P列）— 週平均で ◎+△ が 80% 以上
2. **ルール遵守**（S列）— NG が 0
3. **急変 STOP** — 発生時にログで確認済み
4. **純損益**（J列）— 試験ロットでは参考値（本番移行後に本格評価）

## 売買履歴 — 列定義（拡張版）

| 列 | ヘッダー | 入力 | 説明 |
|----|----------|------|------|
| **A** | 日時 | 自動 | 注文実行時刻 |
| **B** | 売買 | 自動 | `買い` / `売り` |
| **C** | 価格 | 自動 | 指値価格（円） |
| **D** | 数量(BTC) | 自動 | 例: `0.0001` |
| **E** | 約定 | 手動 | `約定` / `未約定` / `DRY_RUN` |
| **F** | 手数料(円) | 手動 | 約定後に bitbank 履歴から転記 |
| **G** | 環境 | 手動 | 注文時の環境ラベル |
| **H** | 損益(円) | 手動 | 売り約定時に計算（買いは空欄） |
| **I** | メモ | 自動/手動 | `トラリピ` `スイング` 等 |

---

## 日次集計 — 数式例（2行目以降にコピー）

日付は **A2** に `2026-05-22` のように入力（セル書式: 日付）。

```
E2 取引回数:
=COUNTIFS(売買履歴!$A:$A,">="&$A2,売買履歴!$A:$A,"<"&$A2+1,売買履歴!$B:$B,"<>")

F2 買い回数:
=COUNTIFS(売買履歴!$A:$A,">="&$A2,売買履歴!$A:$A,"<"&$A2+1,売買履歴!$B:$B,"買い")

G2 売り回数:
=COUNTIFS(売買履歴!$A:$A,">="&$A2,売買履歴!$A:$A,"<"&$A2+1,売買履歴!$B:$B,"売り")

J2 純損益:
=IF(OR(H2="-",H2=""),"-",H2-IF(I2="",0,I2))
```

**注意**: 売買履歴 A列の日時は `yyyy-MM-dd HH:mm:ss` 形式。日付比較が効かない場合は手入力で構いません。

### 週次サマリー（日次集計シート下部または別セル）

```
試験週の環境精度:
=COUNTIF(P2:P8,"◎")&"◎ / "&COUNTIF(P2:P8,"△")&"△ / "&COUNTIF(P2:P8,"×")&"×"

週間純損益合計:
=SUMIF(J2:J8,"<>-",J2:J8)

ルール遵守 NG 日数:
=COUNTIF(S2:S8,"NG")
```

## 運用ログ — 列（参考）

| 列 | 内容 |
|----|------|
| A 日時 | 5分ごと |
| B 環境 | レンジ / トレンド（アップ）等 |
| C 操作 | トラリピ / スイング / STOP 等 |
| D BTC価格 | |
| E モード | idle / toraripi / swing / stopped |
| F ADX | |
| G ER | |
| H JPY残高 | |
| I BTC残高 | |
| J 詳細 | |

**環境切替回数（C列）の数え方**: 同じ日の B列を上から見て、前行と異なる回数を数える（Excel/Sheets 手動 or フィルタ）。

---

## 毎日の更新手順（5分）

1. **運用ログ** — その日の行が増えているか確認（GAS トリガー稼働）
2. **売買履歴** — 約定があれば E〜H 列を手動補完
3. **日次集計** — 新しい行を1行追加し A〜U を記入
4. **2週間試験** — 該当日のチェック欄に ✓

## 毎週日曜（15分）

1. 日次集計 7 行分の週次サマリー数式を確認
2. 環境精度 × が 2 日以上 → 判定閾値の見直し候補としてメモ
3. ルール遵守 NG が 1 日でもあれば原因を U 列に記録
4. **2週間試験** シートの週次セクションを更新
