# チームG-CFX — レンジ（ロング・ショート・暗号資産FX）

> **現在は運用停止（既定）** — `VALIDATION_PAUSED=true`。暗号資産FXの実践は **TEAM-J**（新規・準備中）へ移行。再開時は `VALIDATION_PAUSED=false`。

GMOコイン **暗号資産FX（レバレッジ）** での実践用チームです（**レンジ逆張り**）。  
**ブレイクアウト** は別チーム **G-CBO**（`bitbank-gas-team-g-cbo/`）を使用してください。  
**外国為替FX** は **G-FFX**（`bitbank-gas-team-g-ffx/`）を使用してください。

## 対象銘柄（既定10）

`btc_jpy`, `eth_jpy`, `xrp_jpy`, `sol_jpy`, `doge_jpy`, `link_jpy`, `ada_jpy`, `ltc_jpy`, `sui_jpy`, `dot_jpy`

## ロジック

G-FX と同一（日足+1Hレンジ、ロング/ショート、半分損切）。

## セットアップ

1. **新しい GAS + スプレッドシート**（G-FFX・G-FXとは別プロジェクト）
2. 本フォルダの `.gs` をすべてコピー
3. スクリプトプロパティ:

| キー | 例 | 説明 |
|------|-----|------|
| `GMO_API_KEY` | （本番必須） | **暗号資産FX用** APIキー |
| `GMO_API_SECRET` | （本番必須） | |
| `DRY_RUN` | `true` | デモ推奨。本番は `false` |
| `PAPER_JPY` | `500000` | 紙トレ初期JPY |
| `META_SPREADSHEET_ID` | （推奨） | メタ層SSのID |
| `GCFX_PAIRS` | 省略可 | 例 `btc_jpy,eth_jpy` |
| `GCFX_MAX_MARGIN_JPY_PER_PAIR` | `50000` | 1銘柄あたり最大証拠金 |
| `GCFX_MAX_OPEN_POSITIONS` | `7` | 同時建玉数 |
| `GCFX_LEVERAGE` | `4` | 証拠金計算用レバレッジ |
| `GCFX_TOUCH_PCT` | `0.12` | 上下限タッチ幅（%） |
| `GCFX_TP_RATIO` | `0.55` | 利確位置 |
| `GCFX_PARTIAL_STOP_RATIO` | `0.5` | 1H損切比率 |

4. **6. シート初期化** → **7. 接続テスト** → **2. 1回実行**
5. **10. 日次レポートトリガー** → **3. 5分トリガー**

## 最低資金テスト

メニュー **「13. 最低資金テスト設定」** で最小構成に切り替えられます（25万円・紙トレ）。

### 1万円本番トライアル（G-CBO と併用）

暗号資産FX口座 **1万円** で G-CFX + G-CBO を同時に試す場合:

| チーム | メニュー | 銘柄 | 同時建玉 |
|--------|----------|------|----------|
| **G-CFX** | **15. 1万円本番トライアル** | XRP/JPY | 1 |
| **G-CFX** | **15b. 1万円・全銘柄探索** | 9銘柄（BTC除外） | 1 |
| **G-CBO** | **16. 1万円本番トライアル** | DOGE/JPY | 1 |

**15b** はレンジの機会が少ないため、複数銘柄を監視しつつ `GCFX_MAX_OPEN_POSITIONS=1` で1建玉のみエントリーします。  
手動設定する場合: `GCFX_PAIRS` を9銘柄に、`GCFX_MAX_OPEN_POSITIONS=1` のまま。

※ **同一GMO暗号資産FX口座**（1万円）を共有。外国為替FX（2万円）は **G-FFX用** で別口座。
