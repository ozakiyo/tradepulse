# BITBANK × GAS — **チームB**（トラリピ専用）

**資金配分はメタ層**（`../bitbank-gas-meta/`）が決定します。

チームA（`bitbank-gas/`）とは **別スプレッドシート・別GASプロジェクト** で運用します。

## 方針

| 項目 | 内容 |
|------|------|
| 戦略 | **トラリピのみ**（スイング・環境切替なし） |
| 間隔 | **ATR（ボラ）** で各トラップ間隔を伸縮（基準50,000円） |
| 本数・レンジ | **RSI + ボリンジャー** で拡大・縮小 |
| 試験ロット | 0.0001 BTC / 本 |

## ロジック概要

### 1. ボラ → トラップ間隔（trapStep）

```
間隔 = 基準50,000円 × (ATR% ÷ 参照1.0%)
クランプ: 30,000〜80,000円（5000円単位）
```

ボラが高い → 間隔を広げる / 低い → 狭める

### 2. RSI + BB → 仕掛けレンジ（本数）

| 条件 | 動き |
|------|------|
| RSI ≤ 35 かつ 価格がBB下寄り | **拡大**（+0.25） |
| RSI ≥ 65 かつ 価格がBB上寄り | **縮小**（−0.25） |
| BB幅が狭い（スクイーズ） | **縮小**（−0.15） |
| BB幅が広い | **やや拡大**（+0.10） |

```
下限幅 = (最大本数−1) × 間隔 × span係数
本数 = 下限幅 ÷ 間隔 + 1（最大30本）
```

## ファイル構成

| ファイル | 内容 |
|----------|------|
| `Config.gs` | 設定・状態（`B2_STATE`） |
| `BitbankApi.gs` | bitbank API |
| `Indicators.gs` | ATR / RSI / ボリンジャー |
| `Toraripi.gs` | グリッド計画・実行 |
| `SheetLog.gs` | `B2_運用ログ` / `B2_売買履歴` / メタ層報告 |
| `Main.gs` | メニュー・トリガー |

## セットアップ

1. 新規スプレッドシート → Apps Script
2. `bitbank-gas-team-b/` の `.gs` を **7ファイルすべて** コピー（`Config` `BitbankApi` `Indicators` `Toraripi` `SheetLog` `Main`。`MetaReport` は不要・`SheetLog` に統合済み）
3. スクリプトプロパティを設定
4. メニュー **チームB Bot** → **6. シート初期化**
5. **2. 1回だけ実行**（`DRY_RUN=true`）
6. **3. 1分トリガーを設置**（本番運用。試験中は負荷に応じて10分でも可）

## トラブルシュート

### `使用できないアドレス: https://public.bitbank.cc/...`

| ポイント | 内容 |
|----------|------|
| **6. シート初期化** | API **不要**（シートを作るだけ） |
| **2. 1回実行** | bitbank API **必要**（ここでエラーになる） |

**対処（初回必須）:**

1. Apps Script エディタを開く  
2. 関数 **`b2TestConnection`** を選択 → **実行**  
3. 「承認が必要」→ Google アカウント → **詳細** → **（安全ではないページ）に移動** → **許可**  
4. 「外部サービスへのアクセス」も **許可**  
5. `bitbank 接続OK` と出たら、スプレッドシートに戻り **2. 1回実行**

Google Workspace 利用時は、管理者が `UrlFetchApp` や外部 URL を制限している場合があります。

### 「スクリプトを実行しています」のまま止まる

| 原因 | 対処 |
|------|------|
| `META_SPREADSHEET_ID` 設定済み | エディタで **`b2TestMetaSpreadsheet`** を1回実行して権限許可 |
| 更新前のコード | `MetaReport.gs` 等を最新版に差し替え（一括書き込み対応済み） |
| 実行中 | Apps Script → **実行数** で完了/エラーを確認。 **5. ログを表示** で `実行開始` 以降を確認 |

DRY_RUN では **実JPY残高は一切見ません**。紙ウォレット **30万円**（`PAPER_JPY`）だけでグリッドを組み立てます。bitbank口座のJPYが少なくてもそのまま通ります。

## スクリプトプロパティ

| キー | 既定 | 説明 |
|------|------|------|
| `BITBANK_API_KEY` | — | 必須 |
| `BITBANK_API_SECRET` | — | 必須 |
| `DRY_RUN` | true | 試験中は true |
| `TORARIPI_WIDTH_JPY` | 50000 | **基準トラップ間隔**（固定設定値） |
| `GRID_LEVELS` | 30 | 最大本数 |
| `BTC_PER_LEVEL` | 0.0001 | 1本あたりBTC |
| `PAPER_JPY` | 300000 | DRY_RUN時の紙JPY（試験用） |
| `META_SPREADSHEET_ID` | — | メタ層SS（任意） |
| `ATR_REF_PCT` | 1.0 | ATR基準 |
| `RSI_EXPAND_BELOW` | 35 | 拡大RSI閾値 |
| `RSI_CONTRACT_ABOVE` | 65 | 縮小RSI閾値 |

## チームAとの違い

| | チームA | チームB |
|---|---------|---------|
| モード | レンジ/中立/トレンド/STOP切替 | トラリピ常時 |
| 間隔 | 固定50,000円 | **ATRで変動** |
| 本数調整 | ATRのみ | **RSI+BB** |
| LINE通知 | 環境変化時 | なし（ログのみ） |
