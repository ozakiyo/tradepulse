## メタ層の役割

1. **相場環境分析**（1H: ER / ADX / 急変 / トレンド方向）
2. **資金配分**（A〜E + 現金 = 100%）
3. **週次成績調整**（`META_週次成績` 最新行で 1位+5pt / 最下位-5pt）
4. **改善所見のログ出力**（`META_運用ログ`）

## 各チームとの連携

メタ層実行後、スクリプトプロパティ `META_ALLOCATION` に JSON が保存されます。

```json
{
  "teams": { "A": 35, "B": 30, "C": 15, "D": 10, "E": 5 },
  "cash": 5,
  "regimeKey": "mixed",
  "recommendation": "..."
}
```

各チームは今後 `TEAM_ID`（A/B/…）に応じて `teams.X` % をロット上限に反映します（次フェーズで実装）。

## 週次成績の入力

`META_週次成績` シートの **最新行** に各チームの週間純損益（円）を入力すると、次回計算から自動調整されます。

| 週終了日 | A損益 | B損益 | C損益 | D損益 | E損益 | メモ |
|----------|-------|-------|-------|-------|-------|------|

## 紙トレード競争（各30万円 × 5 = 150万円）

実口座にJPYがなくても、**紙トレード**で5チームを競わせます。

| シート | 内容 |
|--------|------|
| `META_紙トレード` | 全チームの売買イベント（自動追記） |
| `META_競争比較` | **単体** vs **メタ配分** の損益ダッシュボード |

### 2つの見方

| モード | 意味 |
|--------|------|
| **単体運用** | 各チームが **30万円フル** で独立運用した場合の損益合計 |
| **メタ配分運用** | 合計 **150万円** を配分%どおり配分し、各チームの損益率を按分した損益 |

```
メタ貢献損益(チームA) = 150万 × A配分% × 単体損益率(A)
メタ評価額 = 配分額合計 + 貢献損益合計 + 現金待機
```

### チームA/B からの自動報告

各チームGASのスクリプトプロパティに **メタ層スプレッドシートID** を設定:

```
META_SPREADSHEET_ID = （メタ層SSのURLの /d/ と /edit の間）
```

`DRY_RUN=true` の売買ログが `META_紙トレード` に追記されます。  
`metaRunOnce` 実行時に `META_競争比較` が自動更新されます。

D 未稼働時は 30万円・損益0 として表示されます。

## 稼働中チーム（META集計対象）

`META_ACTIVE_TEAMS` に含まれるチームのみ、統合レポート・オート総括・リーグ・Go/No-Go に **掲載・集計** されます（過去行も読み飛ばし）。

| チーム | 状態 |
|--------|------|
| **F-Short** | **稼働中（集計対象）** |
| 上記以外（A, B, E, G-SAXO, G-FFX 等） | **停止** — META 集計から除外 |

再開時: `MetaReport.gs` の `META_ACTIVE_TEAMS` にチーム名を追加して push。

## カテゴリ別リーグ（週次競争）

全チーム **一律50万円** でスタートし、**直近7日間の純損益率（%）** で競います。  
統合レポート実行後（メニュー **11. 統合レポート**）または **12. リーグ順位を更新** で順位・助言が更新されます。

| リーグ | チーム | 比較指標 |
|--------|--------|----------|
| **L1 bitbank現物** | A, B | （停止中） |
| **L2 FX紙** | E-FX, F-FX | （停止中） |
| **L3 マルチ資産** | **F-Short** | **稼働中** |
| **L4 レンジ多資産** | G-SAXO | （停止中） |

- **順位対象**: 7日間の約定 **3件以上**
- **オートの役割**: 7日成績から **`META_リーグ調整` を自動生成**し、各チームが次回実行時に反映
- **リーダーの役割**: `META_リーダー助言` で背景を確認。手動上書きは `META_LEAGUE_AUTO=false` で停止可能

### 自動調整（`META_リーグ調整`）

リーグ更新のたびに全チーム分を再計算し、各チーム GAS / G-SAXO が 1 時間キャッシュで読み込みます。

| 条件 | 調整内容 |
|------|----------|
| 7日損益 ≤ -10% | 新規停止 + ロット20%縮小 |
| 7日損益 ≤ -8% / -3% | ロット15% / 8%縮小 |
| 最下位かつ1位差 ≥ 2% | 防御強化（レンジは touch +2%） |
| 1位差 ≥ 5%（2位以下） | 追い上げ（touch -3%、利確短縮など） |
| 1位差 ≥ 3% | 様子見強化（touch -2%） |
| 勝率高・PF < 1 | 利確延伸 tp +2% |
| PF < 0.75 かつ勝率 ≥ 50% | 利確延伸 tp +3% |

- **ロット増はしない**（1位好調は現行維持）。下位チームは touch / tp / サイズ縮小で改善を狙う
- GAS: `META_LEAGUE_AUTO` 既定 **true**（`false` で無効）
- G-SAXO: `GSAXO_META_LEAGUE_AUTO` 既定 **true**
- 各チームに **`META_SPREADSHEET_ID`**（メタ層 SS）を設定すること

### 運用フロー（週次）

1. オートが統合レポート＋リーグ順位を更新 → **`META_リーグ調整` も同時更新**
2. 各チームは次回トリガー実行時に自動反映（手動変更不要）
3. リーダーは `META_リーダー助言` で理由を確認し、必要なら `META_LEAGUE_AUTO=false` で一時停止
4. 来週の成績で再評価

※ 相場連動ロット（ATR等）は各チーム内ロジックで実施（リーグ調整と独立）。

| シート | 内容 |
|--------|------|
| `META_リーグ` | リーグ別順位（最新） |
| `META_リーグ調整` | **自動パラメータ**（sizeMult / tp / touch / pauseNew） |
| `META_リーダー助言` | チーム別・オート助言・調整候補・来週の重点 |
| `META_調整可能項目` | チームごとに動かせるプロパティ一覧 |
| `META_週次リーグ` | 週ごとの1〜3位スナップショット |

### 旧運用（参考）

以前は「助言のみ・パラメータ自動変更なし」でした。**2026-06 より自動反映を再有効化**しています。
